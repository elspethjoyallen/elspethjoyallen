## Selected Projects

### Molecular Dynamics Workflows
- [**VMD Distance-Analysis Pipeline**](https://github.com/elspethjoyallen/vmd-distance-analysis-pipeline) — Analyzes protein distances across MD trajectories and creates MATLAB figures.
- [**VMD Average Frame from Trajectory**](https://github.com/elspethjoyallen/vmd-avg-frame-from-trajectory) — Aligns selected trajectory frames and calculates average coordinates.
- [**Amber Slurm Input-Files Generator**](https://github.com/elspethjoyallen/amber-slurm-input-files-generator) — Creates Amber input files and Slurm scripts for staged molecular-dynamics workflows.

### PyMOL Structure Analysis
- [**PyMOL Structure Comparison**](https://github.com/elspethjoyallen/pymol-structure-comparison) — Aligns two protein structures and highlights spatial differences.
- [**PyMOL Structure Clash Checker**](https://github.com/elspethjoyallen/pymol-structure-clash-checker) — Finds unusually close atom pairs and displays nearby residues.
